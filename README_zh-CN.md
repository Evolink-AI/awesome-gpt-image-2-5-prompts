## 🍌 介绍

**250 条完整 GPT Image 2.5 提示词，按七类创作任务整理。** 涵盖人像、角色设定、插画、广告、旅行手账、图像编辑和连续画面。每个案例均附原始提示词、创作者署名与关联媒体。

本合集来自 52 位创作者的 238 条公开 X 帖子。模型归属依据创作者的说明，案例尚未经独立重新生成验证。参考图、参数设置与后期编辑均可能影响结果。

品牌、角色及名人相关案例为创作者概念作品，并非官方广告或代言。原始提示词与媒体的权利仍归各自权利人所有。
